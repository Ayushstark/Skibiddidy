\section{Problem Statement}
% =============================================================================

The \emph{Wumpus World} is an $n \times n$ grid ($5 \le n \le 15$) in which an
agent starts at cell $(1,1)$ and must reach a single gold tile $G$ while
respecting the following constraints:

\begin{enumerate}
  \item \textbf{No revisits.} The agent may not re-enter any previously visited
        cell.
  \item \textbf{Wumpus avoidance.} Each Wumpus occupies a fixed row and moves
        horizontally according to a deterministic, turn-dependent schedule.  The
        agent must never land on a cell occupied by a Wumpus after the Wumpuses
        shift.
  \item \textbf{Stench limit.} The agent may encounter at most two stench
        percepts (cells adjacent to a Wumpus) during the entire run; a third
        stench encounter terminates the run as a failure.
  \item \textbf{Turn limit.} The total number of moves is capped at
        $T_{\max} = 4n^2$.
  \item \textbf{Time cost.} Each move accumulates a time cost that depends on
        the destination cell type and whether the agent currently perceives a
        breeze (proximity to a pit):
        \[
          \Delta t(\text{cell}, \text{breeze}) =
          \begin{cases}
            1 & \text{cell} = G \\
            1 + 5 + 2\cdot\mathbf{1}[\text{breeze}] & \text{cell} = P \text{ (pit)} \\
            1 - 3 + 2\cdot\mathbf{1}[\text{breeze}] & \text{cell} = T \text{ (time zone)} \\
            1 + 2\cdot\mathbf{1}[\text{breeze}] & \text{otherwise}
          \end{cases}
        \]
  \item \textbf{Wumpus configuration shift.} Landing on a pit ($P$) advances
        the Wumpus configuration counter by $+5$; landing on a time zone ($T$)
        shifts it by $-3$; all other cells leave it unchanged after the
        per-turn advance of $+1$.
\end{enumerate}

\noindent\textbf{Objective.} Find a path from $(1,1)$ to $G$ that satisfies all
constraints and \emph{minimises the total accumulated time cost}.

% =============================================================================
\section{Approach Overview}
% =============================================================================

\subsection{High-Level Strategy}

The solver uses \textbf{A* search} over an augmented state space.  A* is
chosen because:

\begin{itemize}
  \item The state space is finite but large; uninformed BFS/DFS would explore
        exponentially many states without guidance.
  \item An admissible heuristic (lower bound on remaining cost) is available
        (Section~\ref{sec:heuristic}), guaranteeing optimality.
  \item The priority queue naturally prunes branches whose optimistic total cost
        already exceeds the best known solution.
\end{itemize}

A lightweight \textbf{DFS seed search} is run first (capped at
$\max(2000,\,50n^2)$ states) to obtain an initial feasible solution quickly.
This seed tightens the A* pruning bound from the very first iteration.

\subsection{State Representation}

A search state is a tuple
\[
  s = \bigl(\text{pos},\; \text{turn},\; \sigma,\; k,\; M,\; g\bigr)
\]
where:
\begin{center}
\begin{tabular}{ll}
\toprule
Symbol & Meaning \\
\midrule
$\text{pos} \in \{1,\ldots,n\}^2$ & Current agent position \\
$\text{turn} \in \mathbb{N}$ & Number of moves taken so far \\
$\sigma \in \mathbb{N}$ & Wumpus configuration counter \\
$k \in \{0,1,2\}$ & Accumulated stench count \\
$M \in \{0,1\}^{n^2}$ & Bitmask of visited cells \\
$g \ge 0$ & Accumulated time cost \\
\bottomrule
\end{tabular}
\end{center}

The bitmask $M$ encodes the no-revisit constraint directly in the state,
making duplicate detection exact.

\section{Algorithm Description}
% =============================================================================

\subsection{Wumpus Position Function}

Each Wumpus $w$ is characterised by its fixed row $r_w$ and starting column
$c_w^{(0)}$.  At configuration $\sigma$ its column is computed by replaying
the deterministic step sequence:

\begin{definition}[Turn steps]
For row $r$ and turn $t$, define
\[
  \text{steps}(r, t) =
  \begin{cases}
    [+1,+1,+1,-1] & r \text{ even},\; t \text{ odd (Turn A)} \\
    [+1,-1,-1,-1] & r \text{ even},\; t \text{ even (Turn B)} \\
    [-1,-1,-1,+1] & r \text{ odd},\; t \text{ odd} \\
    [-1,+1,+1,+1] & r \text{ odd},\; t \text{ even}
  \end{cases}
\]
Each step is applied with boundary clamping: $c \leftarrow \max(1,\min(n,c+\delta))$.
\end{definition}

Results are memoised in a hash map keyed by $(r_w, c_w^{(0)}, \sigma)$,
giving $O(1)$ amortised lookup after the first computation.

\subsection{Admissible Heuristic}
\label{sec:heuristic}

\begin{definition}[Optimistic cost table]
Let $h^*(p, s)$ denote the minimum possible additional time cost to reach $G$
from position $p$ in at most $s$ further steps, \emph{ignoring} Wumpus
positions, stench limits, and revisit constraints.  It is computed by
backward dynamic programming:
\[
  h^*(G, s) = 0 \quad \forall s \ge 0
\]
\[
  h^*(p, s) = \min_{q \sim p}\bigl[\Delta t(q) + h^*(q, s-1)\bigr]
\]
where $q \sim p$ denotes grid-adjacent cells and $\Delta t(q)$ is the
entry cost of $q$ (with breeze flag set to \texttt{true} for a worst-case
lower bound).
\end{definition}

\begin{lemma}[Admissibility]
$h^*(p, s) \le h(p, s)$ for any actual remaining cost $h(p,s)$ in the
constrained problem.
\end{lemma}
\begin{proof}
The DP relaxes all constraints (no-revisit, Wumpus avoidance, stench limit).
Any feasible path in the original problem is also feasible in the relaxation,
so the relaxed optimum is a lower bound.
\end{proof}

\begin{theorem}[Optimality of A*]
With an admissible heuristic, A* returns a minimum-cost solution whenever one
exists.
\end{theorem}
\begin{proof}
Standard result; see \cite{hart1968}.  The priority key
$f(s) = g(s) + h^*(\text{pos}(s), T_{\max} - \text{turn}(s))$ never
overestimates the true cost-to-go, so A* never prunes the optimal path.
\end{proof}

\subsection{Duplicate State Pruning}

A state $(pos, turn, \sigma, k, M)$ is dominated if a previously expanded
state with the same tuple has a lower or equal $g$-value (and lexicographically
smaller path key on ties).  Dominated states are discarded without expansion.

\begin{remark}
The bitmask $M$ is part of the key, so two paths that visit the same cells in
different orders are treated as distinct states.  This is necessary because the
no-revisit constraint makes future options depend on the exact set of visited
cells, not just the current position.
\end{remark}

\subsection{Pseudocode}

\begin{algorithm}[H]
\caption{Wumpus World A* Solver}
\begin{algorithmic}[1]
\Require Grid $\mathcal{G}$, gold position $G$, constraints
\Ensure Minimum-cost path to $G$, or failure report

\State $h \leftarrow \textsc{BuildOptimisticCostTable}(\mathcal{G}, G)$
\State $s_0 \leftarrow \bigl((1,1),\; 0,\; 0,\; k_0,\; M_0,\; 0\bigr)$
  \Comment{$k_0$: initial stench; $M_0$: start cell visited}
\State $\textit{best} \leftarrow \textsc{DFSSeed}(s_0)$
  \Comment{Quick initial solution}
\State $\mathcal{Q} \leftarrow$ min-heap ordered by $f = g + h$
\State $\mathcal{Q}.\text{push}(s_0)$
\State $\textit{visited} \leftarrow \emptyset$

\While{$\mathcal{Q} \ne \emptyset$}
  \State $s \leftarrow \mathcal{Q}.\text{pop}()$
  \If{$f(s) > \textit{best.cost}$} \textbf{continue} \EndIf
  \If{$s$ dominated in $\textit{visited}$} \textbf{continue} \EndIf
  \State $\textit{visited}.\text{insert}(s)$

  \If{$\text{pos}(s) = G$}
    \State Update \textit{best} if $g(s) < \textit{best.cost}$
    \State \textbf{continue}
  \EndIf

  \For{each neighbour $p'$ of $\text{pos}(s)$}
    \State $s' \leftarrow \textsc{Expand}(s, p')$
      \Comment{Returns \textbf{null} if blocked}
    \If{$s' \ne \textbf{null}$ \textbf{and} $f(s') \le \textit{best.cost}$}
      \State $\mathcal{Q}.\text{push}(s')$
    \EndIf
  \EndFor
\EndWhile

\State \Return \textit{best}
\end{algorithmic}
\end{algorithm}

\section{Complexity Analysis}
% =============================================================================

\subsection{State Space Size}

\begin{proposition}
The number of distinct states is
\[
  |\mathcal{S}| = n^2 \cdot T_{\max} \cdot \Sigma_{\max} \cdot 3 \cdot 2^{n^2}
\]
where $\Sigma_{\max}$ is the maximum Wumpus configuration value reachable
within $T_{\max}$ turns.
\end{proposition}

\noindent In practice $\Sigma_{\max} = O(T_{\max}) = O(n^2)$, so
\[
  |\mathcal{S}| = O\!\left(n^6 \cdot 2^{n^2}\right).
\]

\subsection{Time Complexity}

\begin{center}
\begin{tabular}{lll}
\toprule
Operation & Per-call cost & Total \\
\midrule
Heuristic table build & $O(n^4)$ & Once \\
Heap push/pop & $O(\log |\mathcal{S}|)$ & Per state \\
Wumpus position lookup & $O(1)$ amortised & Per expansion \\
Visited map lookup & $O(n^2)$ (bitmask compare) & Per state \\
\midrule
\textbf{Worst-case total} & \multicolumn{2}{l}{$O\!\left(n^6 \cdot 2^{n^2} \cdot n^2\right) = O\!\left(n^8 \cdot 2^{n^2}\right)$} \\
\bottomrule
\end{tabular}
\end{center}

\noindent\textbf{Practical behaviour.} The admissible heuristic and the seed
solution prune the vast majority of states.  For the supported grid sizes
($n \le 15$) the solver runs in well under one second on typical inputs.

\subsection{Space Complexity}

\begin{itemize}
  \item \textbf{Priority queue:} $O(|\mathcal{S}|)$ states, each storing a
        path of length $O(n^2)$ and a bitmask of $n^2$ bits.
  \item \textbf{Visited map:} $O(|\mathcal{S}|)$ entries.
  \item \textbf{Heuristic table:} $O(n^4)$ entries (steps $\times$ cells).
  \item \textbf{Wumpus cache:} $O(W \cdot T_{\max})$ where $W \le n$ is the
        number of Wumpuses.
\end{itemize}

\noindent Overall space: $O\!\left(n^8 \cdot 2^{n^2}\right)$ worst-case,
dominated by the visited map.

\section{Correctness Argument}
% =============================================================================

\begin{theorem}[Completeness]
If a feasible path from $(1,1)$ to $G$ exists, the solver returns one.
\end{theorem}
\begin{proof}
A* with an admissible heuristic is complete on finite graphs \cite{hart1968}.
The state space is finite (bounded by $T_{\max}$ and $n^2$ cells), so every
reachable state is eventually expanded unless pruned by a strictly better
solution.  The seed search only provides an upper bound; it cannot cause the
optimal path to be pruned because A* only discards states with
$f(s) > \textit{best.cost}$, and the optimal path satisfies
$f(s^*) = \textit{best.cost}^*$.
\end{proof}

\begin{theorem}[Optimality]
The path returned by the solver has minimum time cost among all feasible paths.
\end{theorem}
\begin{proof}
Follows directly from Theorem~1 (admissibility of $h^*$) and the standard
A* optimality proof.
\end{proof}

\section{Algorithm Choice Justification}
% =============================================================================

\begin{center}
\begin{tabular}{lcccc}
\toprule
Algorithm & Optimal & Complete & Guided & Practical for $n \le 15$ \\
\midrule
BFS (uniform cost) & \checkmark & \checkmark & $\times$ & $\times$ \\
DFS & $\times$ & $\times$ & $\times$ & \checkmark \\
Greedy best-first & $\times$ & \checkmark & \checkmark & \checkmark \\
\textbf{A*} & \checkmark & \checkmark & \checkmark & \checkmark \\
\bottomrule
\end{tabular}
\end{center}

A* is the only algorithm in this table that is simultaneously optimal,
complete, and guided by a heuristic.  The DFS seed provides a fast warm-start
that dramatically reduces the effective search space for A*, combining the
speed of DFS with the optimality guarantee of A*.

\section{Data Structures}
% =============================================================================

\begin{description}
  \item[Binary min-heap] Used as the A* priority queue.  Supports
        $O(\log N)$ push and pop.  Implemented directly in TypeScript to avoid
        library overhead.
  \item[Bitmask string] An $n^2$-character binary string encodes the visited
        set.  Lookup and update are $O(n^2)$ but cache-friendly and allocation-
        free after the initial string.
  \item[Nested hash map] $\textit{visited}[\text{stateKey}][\text{visitedMask}]$
        stores the best $(g, \text{pathKey})$ seen for each
        $(\text{pos}, \text{turn}, \sigma, k, M)$ tuple.
  \item[2-D DP table] The $O(n^4)$ optimistic cost table is built once and
        queried in $O(1)$ per heuristic evaluation.
  \item[Wumpus position cache] Hash map from $(r_w, c_w^{(0)}, \sigma)$ to
        position, giving $O(1)$ amortised Wumpus lookup.
\end{description}

\section{Summary}
% =============================================================================

The Wumpus World solver addresses a constrained shortest-path problem on a
dynamic grid by:

\begin{enumerate}
  \item Encoding all constraints (no-revisit, Wumpus avoidance, stench limit,
        turn limit) directly in the state representation.
  \item Using a backward DP to build an admissible heuristic that lower-bounds
        remaining cost.
  \item Running A* with a DFS warm-start to find the minimum-cost path
        efficiently.
\end{enumerate}

The worst-case complexity is $O(n^8 \cdot 2^{n^2})$, but the heuristic and
pruning make the solver practical for all supported grid sizes ($n \le 15$).
Optimality and completeness follow from standard A* theory given the
admissibility of the heuristic.
